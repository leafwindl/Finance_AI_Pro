# 登录功能标准测试用例

## 用例1：正确用户名密码登录
- **前置条件**：用户已注册，账号未被锁定
- **步骤**：输入正确的用户名和密码，点击登录
- **预期结果**：登录成功，跳转到首页，显示用户名

## 用例2：错误密码登录
- **前置条件**：用户已注册
- **步骤**：输入正确用户名，输入错误密码，点击登录
- **预期结果**：提示"密码错误"，登录失败，不跳转

## 用例3：空用户名登录
- **前置条件**：无
- **步骤**：用户名为空，输入任意密码，点击登录
- **预期结果**：提示"请输入用户名"，登录按钮不可用或拦截

## 用例4：空密码登录
- **前置条件**：无
- **步骤**：输入用户名，密码为空，点击登录
- **预期结果**：提示"请输入密码"

## 用例5：连续多次错误密码
- **前置条件**：账号未锁定
- **步骤**：连续输入5次错误密码
- **预期结果**：第5次后账号锁定，提示"账号已被锁定，请30分钟后重试"

## 用例6：SQL注入防护
- **前置条件**：无
- **步骤**：用户名输入 `' OR '1'='1`，密码随意
- **预期结果**：登录失败，不暴露数据库错误信息
