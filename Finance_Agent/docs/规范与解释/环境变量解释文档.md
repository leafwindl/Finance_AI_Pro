# Finance_Agent 环境变量解释文档

> 更新日期：2026-08-07
> 说明：`.env` 位于项目根目录（不进 git），模板见 `.env.example`；启动时 `src/config/settings.py` 加载。
> 核对方式：2026-08-07 对全部变量做 grep 代码引用核对，下表"代码消费点"为实际文件路径。

---

## 1. 数据流总览

```text
.env（项目根目录）
   │
   ├─ DEEPSEEK_* / OLLAMA_TEMPERATURE ──→ 各 agent LLM 加载处（ChatOpenAI）──→ DeepSeek API
   ├─ KB_BASE_URL / KB_TIMEOUT_SECONDS ──→ 各 agent 检索 ──→ 知识库 8002 /api/v1/search
   ├─ ALLOW_LOCAL_KB_FALLBACK ──→ 检索失败分支 ──→ 本地 ChromaDB / 空结果
   ├─ API_HOST / API_PORT / API_RELOAD ──→ server.py uvicorn.run ──→ 本服务 8101
   ├─ AGENT_API_TOKEN ──→ server.py 鉴权装饰器 ──→ 校验 X-Agent-Token 请求头
   └─ EMBEDDING_* / DASHSCOPE_API_KEY ──→ agent2 本地检索（仅降级路径）──→ DashScope API
```

## 2. 变量明细

### 2.1 大模型链路（必配）

| 变量 | 默认值 | 必填 | 代码消费点 | 流向 | 不配 / 配错的后果 |
|------|--------|------|-----------|------|------------------|
| `DEEPSEEK_API_KEY` | — | **是** | `src/models/factory.py`、agent1 `nodes/llm_config.py`、agent2 `handlers/llm_handler.py` + `keyword_extractor.py`、agent3 `models/deepseek.py`、agent4 `modules/llm/llm_client.py`、agent5 `core/handler.py`、agent2 `loader.py` 启动校验 | DeepSeek API | agent2 loader 启动直接报错退出；其余 agent 调 LLM 时鉴权失败 |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 否 | 同上（8 处） | DeepSeek API | 连错端点，全部 LLM 调用失败 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 否 | 同上 + `src/config/models.py` | DeepSeek API | 模型名错 → 模型不存在报错 |
| `OLLAMA_TEMPERATURE` | `0.7` | 否 | `settings.py`、`config/models.py`、`models/factory.py`、agent1 `llm_config.py`、agent2 `llm_handler.py` + `keyword_extractor.py`、agent4 `llm_client.py`、agent5 `handler.py`（共 7 处） | DeepSeek API（沿用旧名） | 影响 agent1/2/4/5 的 LLM 生成随机性；值越大越发散。**例外：agent3 评审任务硬编码 0.2**（2026-08-20 耗时优化，评审=确定性判断，不读此变量） |

> 数据流：`ChatOpenAI(model=DEEPSEEK_MODEL, api_key=DEEPSEEK_API_KEY, base_url=DEEPSEEK_BASE_URL, temperature=OLLAMA_TEMPERATURE, timeout=180, http_client=httpx.Client(trust_env=False))` → 推理请求发往 DeepSeek。

### 2.2 知识库链路

| 变量 | 默认值 | 必填 | 代码消费点 | 流向 | 不配 / 配错的后果 |
|------|--------|------|-----------|------|------------------|
| `KB_BASE_URL` | **空字符串** | 否* | `settings.py`、`src/knowledge/remote_kb.py`、agent1 `nodes/knowledge_retrieval.py`、agent2 `handlers/retriever.py`、agent3 `nodes/retrieval.py`、agent4 `modules/rag/service.py`、agent5 `core/graph.py`、`src/api/server.py`（readiness） | 知识库 8002 | 未配置时 agent2 走本地知识库加载；其余 agent 检索直接报 `knowledge_base_unavailable` |
| `KB_TIMEOUT_SECONDS` | `30` | 否 | 同上（7 处） | 知识库 8002 | 检索超时上限；KB 慢时设小会误判失败 |
| `ALLOW_LOCAL_KB_FALLBACK` | `false` | 否 | `remote_kb.py`、agent2 `loader.py` + `retriever.py`、agent4 `modules/rag/service.py` | 本地 ChromaDB | `false`：KB 失败抛 `knowledge_base_unavailable`（走错误事件）；`true`：降级返回空结果不报错 |

> \* `KB_BASE_URL` 未配置时：agent2 会尝试加载本地知识库（ChromaDB）；agent1/3/4/5 检索直接失败。当前默认配置指向 `http://127.0.0.1:8002`。

### 2.3 服务自身

| 变量 | 默认值 | 必填 | 代码消费点 | 流向 | 不配 / 配错的后果 |
|------|--------|------|-----------|------|------------------|
| `API_HOST` | `127.0.0.1` | 否 | `settings.py` → server.py `uvicorn.run` | 本服务 | 绑错地址外部访问不到 |
| `API_PORT` | `8101` | 否 | 同上 | 本服务 | 端口被占则启动失败 |
| `API_RELOAD` | `false` | 否 | 同上 | 本服务 | 开发用热重载；生产必须 false |
| `AGENT_API_TOKEN` | 未配置 | 否 | `src/api/server.py` `_require_agent_token` | 请求头校验 | 未配置=放行；配置后请求必须带 `X-Agent-Token` 且值一致，否则 401 |
| `AGENT5_DB_DSN` | 见默认 | 否 | `agent5/core/checkpointer.py` | PostgreSQL | agent5 多轮记忆的连接串；不配时回退 `postgresql://postgres:finance_ai_dev@127.0.0.1:5432/knowledge_agent`；PG 不可达时记忆降级为单轮对话 |

### 2.4 兼容 / 降级用（一般不用动）

| 变量 | 默认值 | 代码消费点 | 流向 | 说明 |
|------|--------|-----------|------|------|
| `EMBEDDING_PROVIDER` | `dashscope` | `settings.py`、agent2 `handlers/retriever.py` | DashScope / 本地 | 仅 agent2 本地检索降级路径使用 |
| `EMBEDDING_MODEL` | `text-embedding-v1` | 同上 | DashScope / 本地 | 同上 |
| `DASHSCOPE_API_KEY` | 空 | 同上 | DashScope API | 仅降级路径用；未配置时本地检索 embedding 会失败 |

> **已清理（2026-08-07）**：`OLLAMA_MODEL`、`OLLAMA_BASE_URL` 已从 `.env` / `.env.example` 删除（旧 Ollama 方案残留，代码有默认值兜底）；`OLLAMA_REASONING` 删除（0 代码引用）。**注意**：`settings.py` 中仍保留 `OLLAMA_MODEL` / `OLLAMA_BASE_URL` 的默认值读取，agent2 `loader.py` 仍将其作为 API Key 的兜底校验项——不配置时不影响 DeepSeek 方案。

## 3. 部署核对清单（按数据流）

1. **模型能跑**：`DEEPSEEK_API_KEY` 必填（缺了 agent2 启动直接退出）
2. **检索能通**：确认 `KB_BASE_URL` 指向可达的知识库（本机默认 `http://127.0.0.1:8002`）；或确认 `ALLOW_LOCAL_KB_FALLBACK=true`（KB 挂了不报错，但检索结果为空）
3. **服务能起**：`API_HOST/PORT` 与部署环境一致（本机默认即可）
4. **对外安全**（部署到服务器时）：配 `AGENT_API_TOKEN`，网关转发带 `X-Agent-Token`
5. **历史变量**：Ollama / DashScope 相关不需要动；`OLLAMA_TEMPERATURE` 保留（DeepSeek 温度在用）
