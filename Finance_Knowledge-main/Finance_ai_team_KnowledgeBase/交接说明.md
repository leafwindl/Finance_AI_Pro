## 3. 检索侧改动明细（searcher/）

| 文件 | 改了什么 | 为什么 | 效果 |
|---|---|---|---|
| `kb_search.py` | 合并逻辑改 **RRF（倒数排名融合）** | 原取 max(BM25,向量)，BM25 高分盖掉语义分 | 向量命中能进 top-5，语义检索生效 |
| `kb_search.py` | 合并保留 `bm25_score` / `vector_score` 原始分 | 想分别看字面/语义强度 | 响应多两个分 |
| `kb_search.py` | Neo4j 扩展只取同库实体 + 过滤文档名 | 原会把别库模块名带进扩展词 | 扩展词不污染排序 |
| `kb_search.py` | `get_neo4j_driver()` 移入 try | 原 Neo4j 挂了整个搜索 502 | Neo4j 停，搜索降级继续 |
| `kb_search_server.py` | `SearchHit` 加 `bm25_score`/`vector_score` 字段 | 响应能携带原始分 | /docs 可见 |
| `db_conn.py` | 检索连接 `autocommit=True` | 原挂事务锁会卡死 rebuild | rebuild 不再卡死 |
| `utils.py` | 模型维度 API 兼容写法 | 消除 5.x 警告 | 干净 |

## 6. 复现步骤

```bash
# 0) 环境（见 README）：pip install、.env、模型、Docker、smartcn 插件
cd Finance_ai_team_KnowledgeBase

# 1) 重建知识库（PG + ES + 向量）—— 需已下载模型
python scripts/rebuild_knowledge_base.py --source "你的知识源目录"

# 2) 建图谱
python scripts/build_neo4j_graph.py

# 3) 启动检索
python -m uvicorn searcher.kb_search_server:app --host 127.0.0.1 --port 8002

# 4) 验证
python scripts/topk_eval.py "证券投资基金法" --top-k 5 --similarity
python -m pytest tests -q
```

## 7. 环境依赖重点说明

### 7.1 向量模型（必须，否则语义检索不可用）
- 未上传。从 ModelScope 下载 `BAAI/bge-large-zh-v1.5`（1024 维）。
- `.env` 设 `EMBEDDING_MODEL` 指向本地路径；`ENABLE_VECTOR_SEARCH=true`。
- **不下载的表现**：`vector_score=null`、`vector_count=0`、语义命中的结果不出现。
- **换模型**：功能可跑，但排名/分数会变（效果依赖模型）；换维度不同模型必须重建。

### 7.2 Neo4j（图谱扩展）
- 外部 Docker 服务，端口 7687。`docker compose up -d` 启动。
- 需 `build_neo4j_graph.py` 建图谱；否则 `expanded_keywords` 为空。
- **挂了不报错**：检索降级，只是无扩展词（已做容错）。

### 7.3 ES smartcn 插件
- 容器内安装，不在代码里。`elasticsearch-plugin install analysis-smartcn` + 重启。
- **不装**：rebuild 用 smartcn 建索引会失败。

### 7.4 数据库迁移（网关侧，若跑注册/登录）
- 网关库 `knowledge_agent` 需先跑迁移，否则注册 500：
```bash
cd Finance_AI_FASTAPI && python scripts/apply_migrations.py
```
