## 当前模块或功能  
Security Monitoring & Logging（安全监控日志）—— 集成 `loggerUtil.js`、`helmet`、`CSP`、`Cloudflare WAF`，覆盖日志记录、HTTP 头加固、注入防护、DDoS 缓解。  

## 依赖清单  
|依赖系统/模块|依赖内容|调用方向|必需/可选|  
|---|---|---|---|  
|`loggerUtil.js`|封装 `winston`，按 level（error/warn/info）写入文件/Console|同步调用|必需|  
|`helmet`|设置 `X-Frame-Options`, `X-XSS-Protection`, `Content-Security-Policy` 等安全头|Express Middleware|必需|  
|`Cloudflare WAF`|规则集：SQLi/XSS/RFI/Path Traversal 检测；Rate Limiting；Geo-IP Blocking（越南以外）|网络层|必需|  
|`Qodana` / `OWASP ZAP`|静态/动态扫描工具，非运行时依赖，但影响发布流程|CI/CD 阶段|必需（发布准入）|  

## 正常调用顺序  
1. 请求进入 Express →  
2. `helmet()` 中间件注入安全响应头 →  
3. 路由处理中，`loggerUtil.error()` 记录异常 →  
4. `responseSanitizationMiddleware` 过滤输出 XSS 字符 →  
5. 请求经 Nginx → Cloudflare WAF → 应用服务器；  
6. CI/CD 流水线执行 `qodana scan` 与 `zap-baseline`，失败则阻断发布。  

## 依赖不可用时的处理  
|异常|处理方式|是否重试|对用户/业务的影响|  
|---|---|---|---|  
|`loggerUtil` 写入磁盘失败|降级为 `console.error()`，不影响业务逻辑|否|运维无法排查问题，但用户功能完全正常|  
|`helmet` 中间件被移除|Nginx 层 `add_header` 补充关键头（如 `X-Frame-Options: DENY`）|否|安全头缺失，但 WAF 仍提供基础防护|  
|Cloudflare WAF 规则失效|启用 Nginx `ngx_http_geo_module` 限制非越南 IP（`geo $allowed_country`）|否|DDoS/爬虫防护降级，但核心业务可用|  

## 数据一致性和超时要求  
- **日志完整性**：`error` 级别日志必须 100% 记录（`winston` `exitOnError: false`）；  
- **超时阈值**：`helmet` 处理 ≤ 1ms；WAF 规则匹配 ≤ 5ms；  
- **合规要求**：`CSP` 策略禁止 `unsafe-inline`/`unsafe-eval`；`X-Powered-By` 必须禁用。  

## 建议测试场景  
- 【头注入】`curl -I https://domain.com` 验证 `X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff` 存在；  
- 【CSP】前端注入 `<script>alert(1)</script>`，验证被浏览器拦截且无 console error；  
- 【WAF】发送 `?id=1' OR '1'='1`，验证返回 `403` 且 Cloudflare Ray ID 记录；  
- 【日志】触发 `500` 错误，验证 `logs/error.log` 中包含 `timestamp`, `url`, `stack` 全字段。
