## 系统是什么  
本系统是**面向教育与模拟场景的虚拟股票交易平台**（Stock Trading Platform），定位为一个**全栈式、可容器化部署的金融交易仿真系统**。  
- **解决的核心问题**：提供安全、可控、可审计的虚拟证券交易环境，支持用户完成账户生命周期管理、实时行情感知、限价/市价订单撮合、投资组合动态估值及交易历史追溯等完整闭环操作；同时通过 OTP、Turnstile 人机验证、设备信任链（remembered_devices）等机制强化身份安全边界。  
- **当前 P2 研究范围**：聚焦于**系统级架构设计与核心模块职责界定**，涵盖后端（Node.js/Express）分层治理、前端（React/Vite）状态流组织、数据库实体关系建模（主表数量与清单以《00_统一元数据字典》为准）、以及 Docker/Nginx 的生产就绪部署基线。不涉及高频交易引擎优化、真实市场接入或监管合规认证。

## 主要模块  

| 模块               | 主要职责                                                                 | 输入                                                                 | 输出                                                                 |
|--------------------|--------------------------------------------------------------------------|----------------------------------------------------------------------|----------------------------------------------------------------------|
| **Backend (Node.js)** | 实现 RESTful API 服务，承载业务逻辑、数据持久化与安全控制                              | HTTP 请求（含 JWT Token、OTP、Turnstile Token）、数据库连接、Python 行情爬虫输出（`stock_fetcher.py`） | JSON 响应（含错误码）、数据库写入（Users/Portfolios/Transactions 等）、Cookie（含 HttpOnly JWT） |
| **Frontend (React)**  | 提供交互式 UI，管理用户会话状态、发起 API 调用、渲染行情图表与组合仪表盘                     | 用户操作事件（点击/表单提交）、SSE 事件流（`eventEmitter.js`）、API 响应数据                 | DOM 渲染、路由跳转、Modal 弹窗、实时价格更新（通过 `stockPrice.js` 订阅）                |
| **Database (MySQL/PostgreSQL)** | 持久化核心业务实体，强制执行 ACID 约束与外键完整性（如 `Portfolios.user_id → Users.user_id`） | CRUD 操作请求（经由 Backend Models 层）、初始化脚本（`create[Table]Table.js`）            | 结构化查询结果、事务回滚日志、唯一性冲突报错（如 `UNIQUE KEY (portfolio_id, stock_id)`）     |
| **Security Subsystem** | 实现纵深防御：JWT 认证（`passportConfig.js`）、RBAC 权限校验（`roleBasedAccessControlMiddleware.js`）、设备信任管理（`rememberedDeviceService.js`）、OTP 动态验证（`otpService.js`） | 用户凭证、设备指纹（`visitor_id`）、一次性密码、Cloudflare Turnstile 响应                  | 认证令牌、授权决策（Allow/Deny）、设备信任状态（`confidence_score`, `expires_at`）          |

## 总体业务流程  
1. **用户入口**：访问 `frontend` 静态资源（Nginx 反向代理），触发 `LoginForm.jsx` 提交凭据；  
2. **认证链路**：`index.js` → `userRoutes.js` → `authenticationMiddleware.js`（JWT 解析）→ `userControllers.js` → `userAuthService.js`（含 OTP/设备信任校验）；  
3. **交易执行**：用户在 `Trade/` 页面提交订单 → `trade.js` API 调用 → `orderRoutes.js` → `orderMiddleware.js`（风控检查）→ `orderController.js` → `orderMatchingService.js`（撮合）→ `transactionModel.js` & `holdingModel.js`（持久化）；  
4. **状态同步**：`portfolioCRUDService.js` 实时计算 `cash_balance + Σ(quantity × close_price)` → 更新 `Portfolios.total_value` → 前端通过 `portfolio.js` API 或 SSE 推送刷新仪表盘；  
5. **最终响应**：`responseSanitizationMiddleware.js` 过滤敏感字段 → 返回标准化 JSON 给客户端。

## 外部系统和主要依赖  
- **外部系统**：  
  - Cloudflare Turnstile（人机验证服务，`turnstileService.js` 调用）；  
  - Python 行情数据源（`stock_fetcher.py` 从公开 API 抓取，存入 `stockPriceModel.js`）；  
- **主要依赖**：  
  - 数据库：MySQL/PostgreSQL（支撑 `dbConnect.js` 连接池）；  
  - 容器化：Docker Engine（`Dockerfile` 定义运行时环境）；  
  - 反向代理：Nginx（`nginx.conf` 配置 `/api` 路由转发至 backend）；  
  - 构建工具：Vite（`vite.config.js` 配置 HMR 与打包策略）。

## 系统边界  
**本系统负责**：  
- ✅ 用户全生命周期管理（注册/登录/资料修改/设备信任绑定）；  
- ✅ 虚拟资金账户与证券持仓的 CRUD 及实时估值；  
- ✅ 基于价格优先、时间优先规则的订单撮合与结算（`orderMatchingService.js` + `orderSettlementService.js`）；  
- ✅ 行情数据采集（Python 脚本）、存储（`stockPriceModel.js`）与 API 供给（`stockPriceRoutes.js`）；  
- ✅ 安全基础设施：JWT 签发/校验、OTP 生成/验证、设备指纹识别与信任周期管理。  

**本系统不负责**：  
- ❌ 接入真实交易所或清算所（纯模拟环境，资金为虚拟 USD）；  
- ❌ 提供金融投资建议或风险评级（无 AI 模型，仅展示历史行情与组合绩效）；  
- ❌ 处理真实法币支付（`paymentService.js` 仅模拟 VND→虚拟币兑换，`payment_transactions` 表无银行网关集成）；  
- ❌ 替代监管合规审计（文档明确声明“不用于真实证券公司”）。
