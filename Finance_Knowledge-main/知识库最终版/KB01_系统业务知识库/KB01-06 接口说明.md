## 接口名称和用途
> **统一契约：** 本文为订单创建接口（`/api/orders`）的请求/响应统一契约，请求字段 `symbol/action/order_type`、响应字段 `status/message` 以此为准。

**接口名称**：`/api/orders`（订单创建接口）  
**用途**：接收用户提交的股票买卖订单请求，执行校验、匹配与结算全流程，是交易核心功能入口。

## 调用关系

调用方：前端 React 应用（`pages/Trade.jsx` 中的订单表单）  
服务方：后端 Express.js 控制器（`controllers/orderController.js` → `services/orderCRUDService.js` → `orderMatchingService.js`）  
调用时机：用户点击“Place Order”按钮后；且必须满足：  
- 用户已通过 JWT 认证（`authenticationMiddleware`）；  
- 当前交易会话处于开启状态（`tradingSessionMiddleware`）；  
- 请求经 `orderValidationMiddleware` 校验通过。

## 请求字段
|字段|中文含义|是否必填|取值/范围|示例|
|---|---|---|---|---|
|`symbol`|股票代码|是|数据库 `Stocks.symbol` 表中已存在的值（如 `AAPL`, `NVDA`）|`"AAPL"`|
|`action`|交易动作|是|`"BUY"` 或 `"SELL"`|`"BUY"`|
|`order_type`|订单类型|是|`"LIMIT"` 或 `"MARKET"`|`"LIMIT"`|
|`quantity`|委托数量|是|正整数，且 `SELL` 时 ≤ 用户当前持仓量（`Holdings.quantity`）|`100`|
|`price`|委托价格|条件必填|`LIMIT` 订单必填；`MARKET` 订单可为空；若填写，须在 `ceiling` 与 `floor` 价格范围内（`stockPrices` 表计算）|`170.50`|

## 响应字段
|字段|中文含义|成功取值|失败取值|说明|
|---|---|---|---|---|
|`status`|请求状态|`"success"`|`"error"`|通用状态标识|
|`message`|响应消息|`"Order placed successfully"`|具体错误原因（见下方错误码）|人类可读提示|
|`order_id`|订单唯一标识|UUID 格式字符串（如 `a1b2c3d4-...`）|`null`|仅成功时返回，由 `orderCRUDService.js` 生成|
|`matched_volume`|本次匹配成交量|非负整数（如 `50`）|`0`|`orderMatchingService.js` 匹配结果|
|`remaining_volume`|剩余未匹配量|非负整数（如 `50`）|`0`|`LIMIT` 订单部分匹配时返回|

## 成功示例
~~~json
{
  "status": "success",
  "message": "Order placed successfully",
  "order_id": "a1b2c3d4-e5f6-7890-g1h2-i3j4k5l6m7n8",
  "matched_volume": 50,
  "remaining_volume": 50
}
~~~

## 失败示例
~~~json
{
  "status": "error",
  "message": "Insufficient holding for SELL order",
  "order_id": null,
  "matched_volume": 0,
  "remaining_volume": 0
}
~~~

## 超时、重试和幂等
- **超时**：基于 Node.js 非阻塞 I/O 特性，单次请求处理时限为 `30s`（由 Express `timeout` 中间件设定）；  
- **重试**：前端 `api/` 模块实现指数退避重试（最多 3 次），但 `MARKET` 订单禁止重试（价格实时变动）；  
- **幂等**：`order_id` 由服务端生成并持久化，重复提交相同 `order_id` 将返回 `409 Conflict`（`responseSanitizationMiddleware` 保障）。

## 相关错误码
|错误码|含义|触发条件|文档依据|
|---|---|---|---|
|`401 Unauthorized`|未认证|JWT token 缺失或失效|`authenticationMiddleware`|
|`403 Forbidden`|权限不足|非管理员调用 `/api/admin/session`|`roleBasedAccessControlMiddleware`|
|`404 Not Found`|资源不存在|`symbol` 不在 `Stocks` 表中|`orderValidationMiddleware`|
|`400 Bad Request`|参数错误|`quantity` 非正整数、`price` 超出 `ceiling/floor`|`orderValidationMiddleware`|
|`422 Unprocessable Entity`|业务拒绝|`SELL` 量 > `Holdings.quantity`|`orderValidationMiddleware`|
|`500 Internal Error`|服务异常|数据库连接失败或 `orderSettlementService.js` 执行中断|`errorHandlingMiddleware`|
