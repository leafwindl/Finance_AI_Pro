# 00_统一元数据字典

生成时间：2026-08-06（本次为补齐缺失治理文档并校准枚举值）
适用范围：本目录下六库（KB01~KB06）全部知识文档。Dify 中只创建括号前的英文字段名。

## 字段定义

| 字段名 | 类型 | 允许枚举/取值 | 是否必填 | 说明 |
|---|---|---|---|---|
| kb_code | string | KB01、KB02、KB03、KB04、KB05、KB06 | 是 | 知识库大类，必须与所在文件夹匹配 |
| doc_type | string | 见下方按库枚举 | 是 | 知识类型，必须与 kb_code 匹配 |
| record_id | string | 见下方前缀规范 | 是 | 知识文档唯一编号，全库唯一 |
| dataset_version | string | P2 | 是 | 数据集版本（当前基准） |
| system | string | ZJQ_TRADE | 是 | 系统编码 |
| module | string | 见下方模块枚举；不适用则留空 | 是 | 主要模块 |
| source_type | string | mixed_simulated、official_web、public_reference（待补链接后启用） | 是 | 来源类型 |
| status | string | draft、approved | 是 | 审核状态；仓库未核验前一律 draft |
| business_version | string | 自由文本；无则留空 | 否 | 业务版本；版本类文档填"待核验" |

## record_id 前缀规范

| 知识库 | 前缀 | 当前使用 |
|---|---|---|
| KB01 | AIZ-GEM-xxx | 001~046 |
| KB02 | REG-ZJQ-xxx | 001~005 |
| KB03 | REQ-ZJQ-xxx | 001（需求变更记录样例）、002~009（需求评审案例） |
| KB04 | AC-GEM-xxx | 001~007 |
| KB05 | AEF-GEM-xxx | 001~004 |
| KB06 | STD-ZJQ-xxx | 001~009 |

规则：
- 同一知识库内按序号连续分配，不跳号。
- KB05-04 原 record_id 为 `P2-KB05-004`，与 KB05 前缀（AEF-GEM-*）不一致，本次已改为 `AEF-GEM-004`。
- KB03 需求变更记录样例原为 `REQ-ZJQ-010`，导致 REQ-ZJQ-001 缺失，本次已改为 `REQ-ZJQ-001`。

## 格式要求

- 元数据表位于文档"文档登记信息（供人工管理）"章节，字段中文名（括号内）仅作人工理解，Dify 中不创建。
- 2026-08-07：本批 87 份文档已完成核验，status 统一为 approved；后续新增或变更文档仍需核验后方可标 approved。
- business_version：版本变化/变更记录类文档填"待核验"，其余留空。
