# Finance AI Vue — 前端设计方案文档

> 文档性质：初始 UI/组件设计稿。文中涉及 Dify、旧 `chat.js`、内存会话和仅靠 localStorage 持久化的内容属于历史方案。当前运行架构和接口以 [README](README.md) 与 [Gateway 接口契约](docs/gateway-api.md) 为准。

## 一、项目概述

**Finance AI** 是一个面向金融领域的 AI 智能助手平台，前端基于 Vue 3 构建。用户可以在平台上选择不同的金融 AI 智能体进行对话咨询，涵盖投资顾问、风险管理、财务会计、商业分析四大场景。

### 核心特点

- **仪表盘 + 聊天双页面**：首页为数据概览仪表盘，选择一个智能体后跳转到独立的全屏对话页面
- **类 Slack/DingTalk 布局**：左侧固定侧边栏导航 + 右侧主内容区
- **4 个独立智能体**：每个智能体维护独立的对话上下文，切换时各自保留会话状态
- **金融专业风格**：深蓝色调，克制、专业、数据感的设计语言
- **暗色/亮色双主题**：支持一键切换，自动记忆用户偏好

## 二、页面结构与交互流程

### 2.1 整体布局框架

```
┌──────────────────────────────────────────────────────┐
│  ┌──────────────┬─────────────────────────────────┐  │
│  │              │                                 │  │
│  │   侧边栏     │         主内容区                 │  │
│  │   280px      │         flex: 1                 │  │
│  │   固定宽度   │         自适应宽度               │  │
│  │              │                                 │  │
│  └──────────────┴─────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

- 侧边栏和主内容区并排，撑满整个浏览器视口（100vh），无全局滚动条
- 主内容区内部自行管理滚动（如聊天消息列表的滚动）
- 无传统顶部导航栏，所有导航功能集成在侧边栏中

#### 品牌区 (SidebarBrand)
- 渐变色 Logo 图标（蓝色系），旁跟应用名称"Finance AI"
- 副标题小字"智能财务助手"
- 点击 Logo 区域可返回仪表盘首页

#### 智能体导航列表 (SidebarAgentList)
- 标题"AI 助手"，字体加粗
- 4 个智能体条目，每个条目包含：
  - 左侧：圆形图标（Element Plus 图标组件，蓝底白色图标）
  - 右侧：智能体名称（主文字）+ 分类标签（次要文字，小号灰色）
- 当前选中的条目：左侧有一道蓝色竖条高亮标记，背景色微变
- 鼠标悬停：背景色变化，有轻微过渡动画
- 点击任意条目：路由跳转到 `/chat/:agentId`

#### 最近对话 (SidebarHistory)
- 标题"最近对话"
- 最多显示 10 条记录，超过后可滚动
- 每条记录显示：对话标题（截断省略）+ 相对时间
- 点击可跳转到对应智能体的对话页
- 无数据时显示："暂无对话记录"
- 数据持久化到 localStorage

#### 用户区 (SidebarUser)
- 用户头像（圆形，默认头像图标）+ 用户名
- 主题切换按钮（太阳/月亮图标），圆形按钮
- 始终固定在侧边栏底部

```
│  │                           [📨 发送]   │   │
│  └────────────────────────────────────────┘   │
└────────────────────────────────────────────────┘
```

#### ChatHeader — 聊天顶部栏
- 左侧：智能体图标（渐变色圆形） + 名称 + 分类标签
- 名称旁有绿色小圆点表示"在线"状态
- 右侧：`[新对话]` 按钮（次要按钮样式）
- 底部有分割线

#### ChatMessages — 消息列表区
- 占满剩余高度，内部 `overflow-y: auto`
- 支持深色/浅色两套气泡配色
- **AI 消息**：
  - 左对齐，带头像（小圆形渐变色图标）
  - 气泡：浅色背景、圆角（左上小圆角，其余大圆角）、微阴影
  - 文字支持换行和长文本自动折行
- **用户消息**：
  - 右对齐，无头像
  - 气泡：渐变色背景（蓝色系）、白色文字、圆角（右上小圆角，其余大圆角）
- **加载中状态**：3 个跳动圆点动画（与参考项目一致）
- **新消息到达时自动滚动到底部**

#### ChatComposer — 输入区域
- 首次进入对话时（无历史消息），显示 3 个建议问题按钮
- 可点击建议问题直接发送
- 多行文本输入框（textarea，3 行高度，不可拖拽调整大小）
- 最多输入 2000 字符，右下角显示字符计数
- Enter 键直接发送，Shift+Enter 换行
- 输入框为空时发送按钮禁用
- 发送按钮：主色调按钮，带图标，loading 状态时显示旋转动画

#### 对话交互细节
- 发送消息后，输入框清空，发送按钮进入 loading 状态
- 显示打字动画（3 个跳动点）
- 收到回复后，动画消失，消息追加到列表
- 对话过程中侧边栏仍可点击切换智能体，当前对话状态保留在内存中
- 点击"新对话"清空当前智能体的消息和 conversation_id，显示新的问候语

### 3.3 智能体切换行为

```
用户在 /chat/requirement-pre-review 和需求预评审智能体对话中
    │
    │ 点击侧边栏"需求AI测试分析智能体"
    │
    ▼
路由跳转到 /chat/ai-test-analysis
    │
    ├─ 如果需求AI测试分析智能体没有历史对话 → 显示问候语 + 建议问题
    │
    └─ 如果之前和需求AI测试分析智能体聊过 → 恢复之前的消息列表

用户再次点击侧边栏"需求预评审智能体"
    │
    ▼
路由跳转回 /chat/requirement-pre-review
    │
    └─ 恢复之前的对话内容，可以继续提问
```

- 切换时保留消息列表不会丢失（当前浏览器会话期间）
- 但 `conversation_id` 是后端 Dify 维护的，所以即使刷新了页面，只要还保留之前的 `conversation_id`，后端仍然能识别上下文（但前端当前版本刷新后会丢失）

## 四、视觉设计规范

### 4.1 色彩系统

#### 亮色模式（默认）

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | `#0f6cbd` | 金融蓝，用于按钮、链接、高亮 |
| 主色浅 | `#3d90d6` | 悬停态 |
| 主色深 | `#0b5496` | 按下态 |
| 背景色 | `#f5f7fa` | 页面背景 |
| 卡片/面板背景 | `#ffffff` | 白色卡片 |
| 侧边栏背景 | `#1e293b` | 深蓝灰色（侧边栏专用暗色） |
| 侧边栏文字 | `#cbd5e1` | 浅灰文字 |
| 侧边栏高亮 | `#0f6cbd` | 选中项高亮色 |
| 正文色 | `#303133` | 主文字 |
| 次要文字 | `#909399` | 辅助说明 |
| 成功/在线 | `#22c55e` | 在线状态点 |
| AI气泡背景 | `#ffffff` | 白色气泡 + 浅边框 |
| 用户气泡 | 渐变蓝 | 主色渐变 |

#### 暗色模式

| 用途 | 颜色值 |
|------|--------|
| 页面背景 | `#0a0a0a` |
| 卡片背景 | `#141414` |
| 侧边栏背景 | `#0f172a`（更深） |
| 正文色 | `#e5eaf3` |
| 次要文字 | `#a3a6ad` |

### 4.2 字体

- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', sans-serif`
- 标题：加粗 700-800，字间距 -0.5px ~ -1.8px（与参考项目一致）
- 正文：常规 400，行高 1.6-1.75

### 4.3 圆角与阴影

- 卡片圆角：16px
- 按钮圆角：10px（小）/ 20px（大）
- 气泡圆角：16px（混合圆角效果）
- 卡片阴影：`0 6px 18px rgba(15, 23, 42, 0.05)`
- 悬停上浮：`translateY(-8px)` + 增强阴影

### 4.4 图标

- 全部使用 Element Plus Icons（全局注册）
- 智能体图标使用对应语义图标（TrendCharts、Warning、DocumentCopy、DataAnalysis）
- 侧边栏使用线性图标风格

## 五、响应式设计

### 桌面端（>1024px）
- 侧边栏 280px 固定宽度，始终可见
- 仪表盘统计卡片 4 列
- 智能体入口卡片 2×2 网格

### 平板端（768px ~ 1024px）
- 侧边栏 240px
- 统计卡片 2×2 网格
- 智能体入口卡片 2×2 网格

### 手机端（<768px）
- 侧边栏默认隐藏，显示汉堡菜单按钮

## 七、智能体定义

### 智能体 1：需求预评审智能体 (requirement-pre-review)

- **图标**：DocumentChecked（文档勾选图标）
- **分类**：需求管理
- **描述**：自动分析需求文档，生成预评审报告，识别需求中的模糊点、遗漏项及潜在风险，并支持将报告同步至Jira，辅助人工三方评审决策。
- **特性标签**：`需求完整性检查` `风险识别` `模糊性分析` `Jira集成`
- **建议问题**：
  - "分析当前需求文档是否完整？"
  - "识别需求中存在的潜在风险点"
  - "生成预评审报告并写回Jira"

### 智能体 2：需求AI测试分析智能体 (ai-test-analysis)

- **图标**：Histogram（柱状图图标）
- **分类**：测试分析
- **描述**：基于需求文档自动生成六维测试分析报告，覆盖功能、性能、安全、兼容性、易用性、可靠性等维度，为测试人员提供全面的测试设计依据和优先级建议。
- **特性标签**：`六维测试分析` `测试点挖掘` `覆盖率评估` `测试优先级建议`
- **建议问题**：
  - "生成该需求的六维测试分析报告"
  - "哪些功能点需要重点测试？"
  - "分析测试的优先级和风险等级"

### 智能体 3：财务会计专家 (accounting-expert)

- **图标**：DocumentCopy（文档图标）
- **分类**：财务会计
- **描述**：专业的财务会计咨询服务。涵盖税务筹划、财务报表分析、会计准则解读和审计辅助等核心财务领域。
- **特性标签**：`税务筹划` `报表分析` `准则解读` `审计辅助`
- **建议问题**：
  - "最新的企业税收优惠政策有哪些？"
  - "帮我解读资产负债表的重点指标"
  - "新收入准则对企业有什么影响？"

### 智能体 4：商业分析顾问 (business-analyst)

- **图标**：DataAnalysis（数据分析图标）
- **分类**：商业分析
- **描述**：基于数据的商业洞察分析引擎。提供战略规划、市场研究、竞品分析和经营诊断，助力企业做出数据驱动的决策。
- **特性标签**：`战略规划` `市场分析` `竞品研究` `经营诊断`
- **建议问题**：
  - "帮我分析这个行业的竞争格局"
  - "如何制定有效的市场进入策略？"
  - "根据销售数据给出经营优化建议"

## 十、关键交互状态

### 加载状态
- 发送消息后，消息区底部显示打字动画（3 个跳动圆点）
- 发送按钮变为 loading 旋转图标，按钮禁用

### 空状态
- 仪表盘最近对话为空：图标 + "还没有对话记录，选择一个智能体开始对话吧"
- 聊天无消息：显示 AI 问候语 + 建议问题

### 错误状态
- API 请求失败：在消息列表中追加一条红色错误气泡
- 网络错误：提示"请求失败：网络连接异常"
- 后端错误：显示后端返回的具体错误信息

### 边界情况
- 输入全空格 → 不允许发送
- 输入超 2000 字符 → 输入框限制 + 字符计数提醒
- URL 输入无效 agentId → 显示"智能体不存在"提示 + 返回首页链接
