# 改动与问题记录 2026-08-15

## 一、agent5 多轮记忆修复（核心）

**问题**:悬浮球助手问"我是谁"时幻觉出"王小明",或答"您还没告诉我名字"。

**根因(三层,修一层暴露下一层)**:

| # | 根因 | 修复 |
|---|---|---|
| 1 | psycopg 无可用驱动实现(报 `no pq wrapper available`) | `pip install "psycopg[binary]==3.2.9"` |
| 2 | DSN 密码不符:代码默认 `finance_ai_dev`,实际 5432 是 Dify 的 postgres(密码 `difyai123456`) | Finance_Agent/.env 加 `AGENT5_DB_DSN` |
| 3 | Windows 事件循环:uvicorn 0.51 把 loop_factory 硬编码为 ProactorEventLoop(无视策略),psycopg 异步只支持 Selector | server.py 顶部设 `WindowsSelectorEventLoopPolicy` + 启动入口 `loop="none"`,并改用 `python -m src.api.server` 启动 |

**验证**:`knowledge_agent` 库生成 checkpoints 等 4 张表;两轮对话("我叫张航" → "我是谁")正确答"张航"。

**注意**:`attach_checkpointer()` 失败后不再重试,任何相关改动都要重启 Agent 进程。
