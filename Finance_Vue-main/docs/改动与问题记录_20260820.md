## 知识库文档上传 V2 适配（前端）

### 背景

后端（`Finance_AI_FASTAPI/app/knowledge_gateway/kb_ingest.py`）已将入库升级为 V2：`POST /knowledge/upload` 改为异步任务（202 + task_id，`kb_code` 可选，不传则后台按块全自动分类），新增 `GET /knowledge/tasks/{taskId}` 轮询接口，结果结构改为块级多库 `{kb_distribution, total_chunks, blocks, kb_code?, doc_id?}`。本次只改前端与接口文档，不修改后端。

### 改动

- `src/services/api/knowledge.js`
  - `uploadToKnowledgeBase(file)` → 支持可选 `kbCode`（非空时追加 `kb_code` 表单字段，兼容人工指定 KB01~KB06）；返回 202 的 `{task_id, ...}`；
  - 新增 `getKnowledgeTask(taskId)`：`GET /knowledge/tasks/{taskId}`；
  - 新增 `uploadDocumentAndWait(file, { kbCode, signal, onProgress, ... })`：提交后轮询到 completed/failed；默认 1.5s 间隔、约 3 分钟上限；支持 AbortController 取消与阶段/百分比进度回调。
- `src/components/KbUploadDropzone.vue`
  - 拖拽框右侧新增「入库分类」下拉：默认「自动分类（推荐）」，可选 KB01~KB06 人工指定；
  - 上传改为异步轮询：进行中显示阶段与百分比；完成后按 V2 结果展示块级多库分布（如「已入库 3 个知识块：KB01×2、KB04×1」）或单库结果（「已入库到 KB02」）；
  - 任务失败展示后端错误信息（含 OUT_OF_SCOPE / 分类服务不可用等），允许重试；多文件保持顺序入库；
  - 提示文案更新为「自动分类入库」。
- `docs/知识库文档上传接口文档.md` 升级为 v2：记录 202 异步契约、`GET /knowledge/tasks/{id}` 完整结构（含 `result` 各字段与 `kb_code/doc_id` 仅单库返回的语义）及 v1→v2 差异表。

### 验证

- `npm run build` 通过（5.90s）；
- 新增 `scripts/verify-upload-v2.mjs`：mock 验收 13/13 通过（下拉选项 / 自动不传 kb_code / 手动传 kb_code=KB02 / 块级多库结果展示 / 单库结果展示 / 失败任务错误提示 / 完成后恢复空闲 / 无直连 8002 等端口 / 上传+轮询请求路径）。
- 真实联调：后端已注册路由但 Gateway（8000）当前未启动；启动后复测 `verify-upload-v2.mjs`（去掉 mock 拦截或切换真实服务）即可。
