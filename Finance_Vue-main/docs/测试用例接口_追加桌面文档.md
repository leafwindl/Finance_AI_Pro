7.4 测试用例编写（前端结构化页面）

前端提供测试用例编写页面（/test-case/write），用户通过结构化表单填写内容后，调
用以下两个操作。两个操作均复用 POST /api/v1/chat，不新增独立端点。

7.4.1 提交评审

接口定义

| 项目 | 内容 |
|------|------|
| 请求方法 | POST |
| 请求路径 | /api/v1/chat |
| 智能体 | agent_id=accounting-expert |
| 响应方式 | SSE 流式（同 7.1） |

请求体示例

{
  "query": "请评审以下测试用例：\n\n"
           "用例名称：创业板批量买入权限校验\n"
           "所属模块：权限校验\n"
           "测试步骤：1. 构造批量买入请求...\n"
           "预期结果：所有记录返回SUCCESS",
  "conversation_id": null,
  "agent_id": "accounting-expert"
}

7.4.2 生成步骤

接口定义

| 项目 | 内容 |
|------|------|
| 请求方法 | POST |
| 请求路径 | /api/v1/chat |
| 智能体 | agent_id=business-analyst |
| 响应方式 | SSE 流式（同 7.1） |

请求体示例

{
  "query": "请为以下功能生成测试步骤：\n\n"
           "功能名称：订单批量提交\n"
           "所属模块：批量委托\n"
           "需求描述：用户通过批量文件上传订单，系统逐笔校验后汇总结果",
  "conversation_id": null,
  "agent_id": "business-analyst"
}

7.4.3 前端表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 用例名称 | 文本输入 | 是 | — |
| 所属模块 | 下拉选择 | 否 | 订单管理/权限校验/账户管理/风控模块/批量委托 |
| 前置条件 | 多行文本 | 否 | — |
| 测试步骤 | 多行文本 | 否 | — |
| 预期结果 | 多行文本 | 否 | — |

操作按钮：
- 提交评审 → POST /api/v1/chat, agent_id=accounting-expert
- 生成步骤 → POST /api/v1/chat, agent_id=business-analyst
